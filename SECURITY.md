# Politique de sécurité

## Versions prises en charge

Seule la dernière version de la branche `main` reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique pour une faille de sécurité.**

Utilisez le [signalement privé de vulnérabilité](https://github.com/mehdibellahsene/e-cheque-/security/advisories/new)
de GitHub (onglet *Security* → *Report a vulnerability*) en précisant :

- la description de la faille et son impact ;
- les étapes pour la reproduire ;
- une proposition de correctif, le cas échéant.

Un accusé de réception est envoyé sous 72 heures, puis un correctif est publié dès que possible.
